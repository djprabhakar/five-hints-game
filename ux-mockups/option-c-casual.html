Design Notes — Option C: Clean & Casual

  • ✦ Light background — familiar, low-fatigue; great for daytime and longer sessions
  • ✦ Vertical hint stack — easier to read top-to-bottom on any screen size
  • ✦ Wrong guess shown inline — your previous guess is shown on the hint row, not in a separate area
  • ✦ Progress bar + pills — glanceable stats without being visually noisy
  • ✦ Group panel at bottom — always available but unobtrusive; collapse for solo
  • ✦ Green accent = active — single accent color creates clear visual hierarchy
  • ✦ Mobile-first layout — full width single column, easy thumb reach
  • ✦ Attempt dots in input — lives visible exactly where you type, zero cognitive load
